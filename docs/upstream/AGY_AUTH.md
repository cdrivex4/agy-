# AGY Authentication Architecture & AGY++ Delegation

## 1. Upstream Auth Model
In Antigravity CLI v1.2.2:
- Authentication relies on the operating system credential store (system keyring on Windows/macOS/Linux) and Google OAuth flows.
- Credentials, refresh tokens, and session cookies are managed privately by the AGY subsystem.
- Diagnostic commands and headers offer flags like `AGY_CLI_HIDE_ACCOUNT_INFO` to sanitize UI logs and headers.

## 2. AGY++ Auth Security Rules
1. **Never Intercept or Scrape**: AGY++ must never parse plaintext OAuth secrets, scrape keyrings, or intercept auth callbacks.
2. **Never Store Secrets**: The AGY++ configuration and session databases must never store access tokens, refresh tokens, or API keys.
3. **Redaction by Default**: Any diagnostics or verbose output generated by AGY++ must automatically redact tokens and identifiers.
4. **Transparent Delegation**: Commands like `/login`, `/logout`, and `/auth status` delegate directly to AGY's supported mechanisms via `AgyAuthAdapter`.
